Reels Studio · 第一版 v1.0.0

短影音小幫手 安裝說明

讓 Claude 幫你把錄音、影片，或一個還沒錄的想法，做成直式短影音（IG Reels／TikTok／YouTube Shorts），字幕、插圖、貼文文案一起準備好。

你的進度已完成 0 項

每做完一步，就點左邊的圓圈打勾。這台電腦的瀏覽器會記住你勾到哪裡。

解壓縮出來的資料夾裡，程式檔（不用打開） 是安裝程式自己要用的你不用打開它，只要照下面的清單一步一步做。

0安裝前，先確認

  1. 需要可以使用 Claude Code 的方案。
  2. Python 和需要的套件約 0.4 GB
    語音辨識模型（第一次聽打時自動下載，只要一次）約 1.6 GB
    安裝過程的暫存檔、做前幾支影片的空間約 1 GB
    合計約 3 GB
    之後每做一支影片：成品約 15–30 MB，加上約 30–50 MB 的工作檔（有用實拍素材會多一些；影片做好後，素材資料夾裡的 _reels_work 可以刪掉）。錄音和影片素材本身可以放在任何一顆硬碟。
    怎麼看還剩多少空間？按 Win + E 打開檔案總管，點左邊的「本機」，C 槽下面會寫「可用 ○○ GB」。
  3. 安裝時要下載 Python 和套件，第一次聽打還會下載約 1.6 GB 的語音辨識模型。
  4. 可略過 讓影片穿插免費的實拍照片和影片。沒有也完全可以用，畫面會全部用插圖。想要的話到 pexels.com/api 免費申請。

1安裝

  1. 在壓縮檔（.zip）上按右鍵 → 「解壓縮全部」，放在哪裡都可以（例如桌面）。
    ⚠️ 不要直接在壓縮檔裡面點兩下那樣安裝會失敗。要先解壓縮，再打開解壓縮出來的資料夾。
  2. 在解壓縮出來的資料夾裡，就在這份說明的旁邊（有些電腦會顯示成 ② 雙擊安裝.bat）。會跳出一個黑色視窗，畫面上的字會顯示進度。
    如果出現藍色的「Windows 已保護您的電腦」點 「其他資訊」，再點 「仍要執行」。這是 Windows 對所有從網路來的檔案都會跳的提醒。
    • 「要自動安裝 Python 嗎？(Y/n)」：直接按 Enter 就是要。它會從 Python 官方網站下載，只裝給你自己，不需要管理員權限，約 1–3 分鐘。
    • 「請貼上 Pexels API 金鑰」：有金鑰就貼上（按右鍵就能貼上，畫面不會顯示是正常的），然後按 Enter；沒有就直接按 Enter 跳過。
    安裝套件那一步會跑出很多英文字，那是正常的，等它跑完就好（約幾分鐘）。
  4. 按任意鍵關掉黑色視窗。
    出現黃色或紅色的問題清單？照畫面上的提示處理，再雙擊一次 ② 雙擊安裝 就好。重複執行不會弄壞東西。
  5. 之後點這個圖示就能再打開控制台（控制台右上角也有這份說明）。沒看到的話，見最下面的「常見問題」。
  6. 這樣 Claude 才會認得剛裝好的小幫手。

2建立你的頻道設定

設定一次，之後每支影片都會自動套用。全部在控制台用點的就好。

  1. 點桌面的 Reels Studio 圖示就會打開。
  2. 會出現在影片上方的小標籤和結尾卡。
  3. 點一個版面風格就會自動出樣張（右邊）。不想跟別人的影片撞款，換風格最有感。
  4. 結尾卡可以選圖示、按鈕文字和下面的小字，例如「每週三更新」。
  5. 可以之後再補 文案語氣、目標觀眾、固定 hashtag 這些。點灰色的小按鈕就能快速填入。
  6. 看到綠色的「已儲存 ✓」就完成了。之後想改，回來改完再儲存一次就好。
不想用控制台？讓 Claude 一題一題問你
  1. 在 Claude 開新的對話，輸入 /reels-studio，或直接說 幫我做 reels。
  2. 回答 Claude 的問題：頻道名稱、內容類型、配色、版面風格、字型、文案語氣、結尾想讓觀眾做什麼、固定 hashtag。
  3. 看它做的樣張，不滿意就用一般的話講，例如 換成藍色 換字型 結尾寫「每週三更新」。

結果跟用控制台設定一樣。想重來，說 重新設定品牌 就可以。

3做第一支影片

  1. 錄音檔（mp3、m4a）或影片檔（mp4、mov）都可以。還沒錄也沒關係，可以先請 Claude 幫你寫稿。
  2. 按「選擇資料夾⋯」選它，就會看到做到哪一步。
  3. 可略過 不選的話就用預設頻道、做 3 支。
  4. 句子裡已經寫好資料夾和頻道，不用再另外說明。長的錄音要先聽打，可能要 30–60 分鐘。
  5. Claude 挑好精華片段後，回到「我的作品」的「選要剪的片段」勾選、改標題，按「確定要剪這幾段」，再照「下一步」把句子貼給 Claude。短影片沒有這一步，可以直接打勾。
  6. 在「我的作品」就能播放。Claude 沒辦法真的「聽」聲音，字幕有錯直接跟它說。
  7. 照「下一步」請 Claude 寫文案、整理發文包，再到 IG／TikTok 自己發文（Claude 不會登入或代發你的帳號）。

一篇文章或一個想法幫我把這篇寫成 reels 口播稿
寫好稿你照著錄，錄好再說 錄好了，幫我剪。
已經剪好的影片幫我寫文案 幫我整理發文包
用控制台更省事在「我的作品」選素材資料夾，「下一步」會告訴你現在該跟 Claude 說什麼，複製的句子會自動寫上資料夾和頻道，在 Claude 開新對話、貼上送出就好。也可以在那裡選片段、播放成品、一鍵複製文案。

5小提醒

  • 剪一支大約要 10–30 分鐘（有露臉的影片比較久），可以同時剪 2 支。這段時間電腦可以做別的事，但不要關機。
  • 第一次聽打會先下載語音辨識模型，會特別久，之後就快了。
  • Claude 沒辦法真的「聽」聲音，成品請自己完整看一遍，字幕有錯直接跟它說。
  • 發文要你自己操作，Claude 不會登入或代發你的帳號。
  • 輸入 /reels-studio 這種斜線指令時，同一則訊息裡不要放網址；有連結的話，用一般句子講就好。

?常見問題

跳出「找不到需要的檔案」，或黑色視窗一閃就不見了

通常是還在壓縮檔裡面執行。請先「解壓縮全部」，再到解壓縮出來的資料夾雙擊 ② 雙擊安裝。

Python 自動安裝失敗

到 python.org/downloads 下載 Python 3.13 自己安裝。安裝畫面第一頁一定要勾選「Add python.exe to PATH」，裝好之後再雙擊一次 ② 雙擊安裝。

安裝時跳過了 Pexels 金鑰，之後想加

按鍵盤的 Win，搜尋「PowerShell」並打開，貼上下面這行（把「你的金鑰」換成真的金鑰），按 Enter，再重開 Claude。

setx PEXELS_API_KEY "你的金鑰"
輸入 /reels-studio 沒有反應

確認安裝最後有出現「全部完成！」，而且有把 Claude 桌面 App 完全關掉再打開。還是不行的話，直接說「幫我做 reels」試試看。

我的頻道設定存在哪裡？可以自己改嗎？

在 C:\Users\你的名字\.claude\reels-studio\my-brand\。裡面的 brand.json 是配色、字型、結尾卡；BRAND.md 是文案語氣和 hashtag。最簡單的方式是在控制台的「頻道設定」修改，或直接跟 Claude 說你想改什麼。控制台只會改你動過的那幾項，Claude 依你的要求記下的其他規則不會被洗掉。

我有好幾個頻道或帳號，怎麼分開設定？

在控制台的「頻道設定」按 「＋ 新增頻道」，輸入名稱，選「從空白開始」或「沿用某個頻道的配色、字型、版面風格和結尾卡」，建好後照平常一樣填寫、儲存。之後在「我的作品」選素材資料夾，在「用哪個頻道的設定」選它並按「儲存設定」，Claude 和剪片程式就會自動套用那個頻道。沒有選的資料夾會用預設頻道。

不要的頻道：在「頻道設定」選它，按 「刪除這個頻道」。它會移到資源回收筒，刪錯了可以從那裡還原。預設頻道不能刪除。

點桌面的 Reels Studio 沒有反應

等 5 秒左右，瀏覽器應該會自己打開。如果還是沒有，直接跟 Claude 說「打開控制台」。控制台只在你自己的電腦上執行，不會上傳任何東西；關掉分頁 15 分鐘後它會自己結束，也可以按右上角的「關閉」。

重新安裝會不會把我的設定洗掉？

不會。重新安裝只會更新程式，你的頻道設定會保留；被替換的舊檔也會先備份到 .claude\backup-reels-studio-日期時間\。
