▶Reels Studio 控制台
使用說明

嗨，今天想做什麼？

這個控制台讓你用點選的方式設定頻道、看做好的影片和文案。實際的聽打、剪片、寫文案，還是交給 Claude。

① 頻道設定

② 最近的作品資料夾

③ 在 Claude 這樣說

建議先到「我的作品」選素材資料夾那裡的「下一步」會把資料夾和頻道一起寫進要貼給 Claude 的句子，複製貼上就好。

下面是通用的說法：在 Claude 桌面 App 開新對話時選素材所在的資料夾，再貼上句子。

頻道設定

影片的配色、字型、結尾卡，以及 Claude 寫文案時要遵守的語氣。設定一次，之後每支影片都會套用。

新增頻道

文案語氣、hashtag 這些說明會從空白開始。按「建立」之後，就會打開新頻道的設定讓你填。

基本

版面風格

字幕、標題卡、背景、插圖線條、動畫和結尾卡的整體樣子。點一個就會出樣張；跟別人的影片撞款時，換一個風格最有感。

逐項調整

從上面選的風格出發，只換你想換的那幾項。

配色

強調色用在標題重點字和按鈕；亮點色用在字幕的重點底色。背景一律是淺色，字幕才看得清楚。

字型

想要更多免費字型？

下載後在字型檔上按右鍵 →「安裝」，再按右上角「關閉」並重新打開控制台，新字型就會出現在清單裡。

結尾卡

給 Claude 看的頻道說明

寫文案、選片段時會照這裡。點灰色的小按鈕可以快速填入，也可以自己打字。

樣張

我的作品

選素材所在的資料夾，看看做到哪一步、播放剪好的影片、複製文案。
