▶Reels Studio 控制台

嗨，歡迎使用 Reels Studio 👋

把錄音、影片或一個想法，做成有字幕和插圖的直式短影音。聽打、剪片、寫文案交給 Claude；這個控制台幫你設定風格、選片段、看成品。

  1. 🎬 選素材資料夾放錄音或影片的資料夾。還沒錄也沒關係，Claude 可以先幫你寫稿。
  2. 💬 複製一句話給 Claude貼到 Claude 桌面 App，它就會接著做。控制台會告訴你現在做到哪一步。
  3. 👀 回來看成品剪好的影片和文案都在這裡看。哪裡想改，點一下就能請 Claude 重剪。

影片的長相（風格）和剪法都有預設，不用先設定就能做。想調的話，隨時到上面的「設定」。

做影片

選放錄音或影片的資料夾，照著一步一步走。每一步都是複製一句話貼給 Claude。

選素材資料夾

👇 在這裡選新的資料夾。選好之後，下面就會換成新資料夾的進度。

還沒有素材，或想直接跟 Claude 說？

在 Claude 桌面 App 開新對話時選素材所在的資料夾，再貼上句子。複製時會自動加上右上角的風格。只有想法、還沒錄音的話，先開一個空資料夾，用第三句請 Claude 寫稿。

設定

決定 Claude 剪片時節奏多快、多常推近、放多少字卡。不想管可以跳過：控制台會看素材自己判斷，用「預設」剪法。同一個剪法可以搭配不同的風格。

設定

影片的版面風格、配色、字型、結尾卡，以及 Claude 寫文案時要遵守的語氣。設定一次，之後每支影片都會套用。

收起展開看三條路

影片風格有三種來法。挑最像你現在情況的那一條，照著站牌走就好。之後想換路線也可以。

要設定別的風格，用右上角的「風格」切換。

新增風格

文案語氣、hashtag 這些說明會從空白開始。按「建立」之後，就會打開新風格的設定讓你填。

基本

版面風格

字幕、標題卡、背景、插圖線條、動畫和結尾卡的整體樣子。預設是第一個自由創作：用文字描述你要的感覺，剪輯師每支自己設計，不會跟別人長得一樣。後面五種是快速套版：選了就固定是那個樣子，點一個就會出樣張，還可以在下面逐項調整。

逐項調整

從上面選的風格出發，只換你想換的那幾項。

自由創作時，標題、字幕、背景、裝飾和轉場都由剪輯師照這裡設計，每支可以不一樣。配色、字型、下面的「版面規則」和剪法照樣會套用。樣張只是備用的樣子，不代表成品。

開頭標題卡的樣子

影片最前面 2–3 秒的問句標題長什麼樣子。要不要放標題卡、背景要不要用圖庫照片，搬到了。

自由創作時，標題卡的樣子由剪輯師每支設計。

版面規則

影片的固定結構。不想每支都有結尾卡，在這裡關掉就好。

關掉結尾卡時，影片在最後一句話說完後結束。節奏搬到了。

配色

先選一個大方向，再從下面挑一組顏色。

強調色用在標題重點字和按鈕；亮點色用在字幕的重點底色。選「深色背景」那組時，字幕框會維持清楚。

樣張

常見問題

照你卡住的地方找。這裡沒有的，直接問 Claude 也可以。

剛開始

我不知道從哪裡開始

直接到「做影片」選放錄音或影片的資料夾，照著步驟走就好。風格和剪法都有預設，不用先設定：影片會先用「自由創作」的樣子，剪法由控制台看素材自己判斷。做過一兩支、知道自己想要什麼樣子，再到「設定」固定下來。

複製的句子要貼到哪裡？

打開 Claude 桌面 App，開一個新的對話，貼上送出。句子後面已經帶著資料夾、風格和剪法，不用再另外說明。

我只有想法，還沒有錄音

先開一個空的資料夾，在「做影片」打開它。第一步會給你一句話，請 Claude 幫你寫口播稿；照著稿子錄好，把錄音放進資料夾，按「重新讀取」就能接著做。

照片、影片、聲音可以怎麼搭配？

三種素材各自選從哪裡來，可以自由搭配。在「做影片」第一步，每一排選一個就好：

  • 照片：用你自己的照片、從免費圖庫找（Pexels／Unsplash），或請 Claude 畫插圖。
  • 影片：用你自己拍的、從免費圖庫找實拍片段，或不用實拍、用插圖動畫。
  • 聲音：你自己錄，或不要聲音（做成純字卡，發文時在 App 裡加音樂）。

例如：照片用自己的、影片從圖庫找、聲音自己錄；或全部交給圖庫和插圖，自己只錄音。選好後，下面會告訴你資料夾裡要放什麼。

AI 生成影片和 AI 配音目前還不支援：選了 AI 生成影片會用插圖動畫代替；配音目前要自己錄，或選「不要聲音」。

可以不錄音、不配音嗎？

可以，做成「純字卡」：在「做影片」第一步把聲音選「不要聲音」（或點「不錄音，做純字卡」），Claude 會把你的主題寫成一張張字卡，每張停留的時間照字數算好，配上插圖做成影片。影片本身沒有聲音，發文時在 IG／TikTok 的 App 裡加音樂就好；用平台的音樂庫，音樂才有授權。

已經寫好口播稿、但不想錄了，跟 Claude 說「我不想錄音，幫我把口播稿改成純字卡，做成影片」。

做影片的時候

做到一半關掉了，怎麼接著做？

打開控制台，在「做影片」的最近的資料夾點一下，會停在你現在做到的那一步，照那一步的句子貼給 Claude 就好。

剪一支要多久？

大約 10–30 分鐘，有露臉的影片比較久，可以同時剪 2 支。這段時間電腦可以做別的事，但不要關機。第一次聽打會先下載語音辨識模型，會特別久，之後就快了。

影片剪好了，為什麼沒有出現寫文案的句子？

剛剪好時，控制台會先請你看影片。看完沒問題，按影片下面的「看起來不錯，下一步」，寫文案的句子就會出現。想改的話，點同一張卡片上的「推近太多」「字卡太少」這類按鈕，請 Claude 重剪。

控制台會記得你看過哪幾支；重剪之後又會先請你看一次。

字幕有錯，或想改其中一支

Claude 沒辦法真的聽聲音，成品請自己完整看一遍。哪一句要改、哪裡想換，直接跟 Claude 說，例如「片段 2 的第三句字幕應該是……」。

影片裡的插圖有哪些現成道具？

沒有露臉的影片會用插圖說故事。下面是已經畫好、可以直接拿來用的道具，顏色會跟著目前的風格。想用哪一個，跟 Claude 說它的名字就好，例如「這段用發芽」「放一個天秤，左邊是錢、右邊是心」。

這些只是現成的，Claude 每支也會照內容另外畫新的插圖，不會只用這幾個。

打開時才會畫，第一次要等幾秒。

做好的影片和文案在哪裡？

都在你的素材資料夾裡。「做影片」最下面可以直接播放、複製文案，或按「在資料夾中顯示」找到檔案。發文包在資料夾裡的 發文包\發文清單.md。

Claude 會幫我發文嗎？

不會。Claude 不會登入或代發你的帳號，發文要你自己到 IG、TikTok 操作。發文包會把封面、文案和發文清單整理好。

想用實拍照片，但安裝時跳過了 Pexels 或 Unsplash 金鑰

按鍵盤的 Win 鍵，搜尋「PowerShell」並打開，貼上下面這行（把「你的金鑰」換成真的金鑰），按 Enter，再把 Claude 桌面 App 完全關掉重開。金鑰到 pexels.com/api 或 unsplash.com/developers 免費申請。

setx PEXELS_API_KEY "你的金鑰"
setx UNSPLASH_ACCESS_KEY "你的金鑰"

用了 Unsplash 的照片，發文時必須標註攝影師，發文包會幫你寫進文案。

控制台說讀不到檔案或影片

檔案放在外接硬碟或雲端資料夾時常會這樣。確認硬碟接好、雲端檔案已經下載到電腦上，再按資料夾旁的「重新讀取」。

剪法

「剪法」和「風格」差在哪裡？

風格是影片看起來怎樣：配色、字型、字幕、版面、結尾卡。剪法是 Claude 怎麼剪：節奏多快、多常推近、放多少字卡、用哪些效果。

兩個分開設定，可以自由搭配。例如同一個頻道風格，訪談用慢一點的剪法，知識分享用快一點的剪法。兩個都在上面的「設定」。

一定要設定剪法嗎？

不用。沒設定的話會用「預設」剪法：控制台看資料夾裡的素材自己判斷，有露臉影片就剪成口播 Reels，只有錄音或字卡就剪成動畫解說，其他照那一類的預設做。剪出來覺得哪裡不對，再來調就好。

懶人、常用、全部差在哪？

只是一次看到多少設定，存的東西都一樣。懶人只問兩件事：這是哪種影片、節奏要多快。常用每一類列出四五個常用設定。全部連「講到列舉就用清單字卡」這種規則都能改。切換時，已經改的設定都會留著。

「一定用」「剪輯師判斷」「不用」是什麼意思？
  • 一定用：講到符合的地方就做，例如每次講到列舉都放清單字卡。
  • 剪輯師判斷：Claude 照節奏和字卡多寡決定要不要做、做幾次，不會每次都做。
  • 不用：這支影片完全不做。
只想讓這一支剪得不一樣

在「做影片」剪片那一步，按剪法那一行的「調整」，在那裡改。改的項目會標成「只有這個資料夾」，只影響這個資料夾的影片，你存好的剪法不會變。覺得改得好，按「存進剪法」，之後用這個剪法的影片都會這樣剪。

看完影片覺得推近太多、字卡太少，怎麼改？

在「做影片」影片下面的「看完影片，哪裡想改？」，點符合的按鈕（可以點好幾個），會先列出要怎麼改。選「只改這個資料夾」或「存進剪法」，再把出現的那句話複製貼給 Claude，它就會照新的設定重剪。

重剪時，原本的影片會改名成「…_舊.mp4」留著，可以比較兩支。不想重剪的片段，從句子裡拿掉就好。

影片類型判斷錯了

例如資料夾裡有露臉影片，但你其實想做成動畫解說。在剪片那一步按「調整」，在「這個資料夾的影片是哪一種？」選對的那個就好，只影響這個資料夾。想讓某個剪法每次都固定用同一種，到「設定 → 剪法」選那個剪法，在影片類型選它。

我有好幾個頻道，可以各用各的剪法嗎？

可以。先用右上角的「風格」切到那個頻道，再到「設定 → 剪法」選要用的剪法，按「設成風格『…』的預設剪法」。之後這個風格的資料夾都會用它；某個資料夾想用別的，在剪片那一步的選單換就好。

原本在風格裡的「節奏」和「開頭標題卡」去哪了？

搬到剪法了：節奏在「節奏和推近」，要不要開頭標題卡、標題卡背景在「字卡」。標題卡的樣子還是在風格裡設定。

你原本設過的不會不見：第一次打開新版控制台時，每個風格原本的節奏和標題卡，會自動搬進一個叫「〈風格名稱〉原本的剪法」的剪法，剪出來跟以前一樣。搬之前的設定也另外備份成 brand.json.剪法之前.bak。

剪法頁右邊的時間條，是我的影片嗎？

不是。那是用一段 44 秒的範例口播，排給你看「照這些設定大概會怎麼剪」。真的剪片時，Claude 會照你的逐字稿判斷哪裡要推近、哪裡放字卡。

設好剪法，Claude 一定會照做嗎？

節奏、要不要開頭標題卡、標題卡背景這三項，剪片程式會直接照做。其他像推近多常、字卡多寡、「講到列舉就用清單字卡」這些，是寫成白話交給 Claude 照著剪，大多數時候會照做，但不是程式強制的。看完影片覺得哪裡沒照做，用「哪裡想改？」的按鈕請它重剪，或直接跟它說。

風格

只想讓這一支換個感覺，不想改風格

把想要的感覺直接寫在要複製的那句話裡，例如「這次想要深色、慢慢浮現的大字」，或點那句話下面的「只用這一次，不用設定風格」。只會套用在這一支。

我有好幾個頻道或帳號

每個帳號建一套風格：到「設定 → 風格」按「＋ 新增風格」。做影片時用右上角的「風格」選要用哪一套，打開的資料夾會記住，下次自動套用。

「自由創作」和「快速套版」差在哪裡？

快速套版選了就固定是那個樣子，樣張看到的就是成品的樣子。自由創作不套版：你用文字描述想要的感覺，Claude 每支自己設計標題、字幕和畫面，比較不會跟別人撞款；樣張只看得出配色和字型，實際樣子要等剪出第一支。

剛安裝的字型沒有出現在清單裡

按右上角「關閉」，再點桌面上的「Reels Studio」重新打開控制台，字型清單才會更新。

重新安裝會不會把我的風格和剪法洗掉？

不會。重新安裝只更新程式，你的風格、剪法和作品都會保留。

控制台本身

怎麼打開、怎麼關掉？

點桌面上的「Reels Studio」就會打開，也可以跟 Claude 說「打開控制台」。用完按右上角「關閉」；直接關掉分頁也可以，15 分鐘後它會自己結束。

怎麼知道有沒有新版？

每次打開控制台都會檢查一次。有新版時，最上面會出現提示，照著下載、解壓縮、雙擊「② 雙擊安裝.bat」就好。沒有網路的話不會檢查，也不影響使用。

控制台會上傳我的東西嗎？

不會。控制台只在你自己的電腦上執行，唯一會連網路的是檢查新版：只讀 GitHub 上最新版的版本號，不會傳送你的設定或檔案。
